# Pulse Price Volatility Analyzer

## Overview
A Java-based mini project that processes grain wholesale price records and flags abnormal fluctuations using sorting and searching algorithms. Built as part of Project-Based Learning (PBL).

## Features
- Load and validate CSV price records
- Compute absolute and percentage price changes
- Sort records by price change
- Search efficiently for threshold crossings
- Flag abnormal fluctuations and export results

## Tech Stack
- Java 11+
- OpenCSV / Apache Commons CSV
- JUnit for testing
- Optional SQLite/H2 for larger datasets
